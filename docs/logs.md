### 问题 3：加速度始终为 0

**操作：**

- 在读加速度数据处置断点，正常停下
- 查看读到的 raw 数据，全部为 0

**后续排查：**

- 加速度 ID、陀螺仪数据、温度读取全部正常，SPI 读写通道确认无问题
- 读回 0x40 寄存器 = 0xAB，确认 Config 的写操作能生效
- 读回 0x7C（使能寄存器）= 0，读回 0x03（状态寄存器）= 0x10，bit7（数据就绪位）一直为 0
- 手动补使能（写 0x7C = 0x04，等 200ms）无效
- 完整最小启动序列（软复位 0xB6 → 使能 → 正常模式 → 量程 → 0x40=0xA8）无效，status 恒 0x10
- 核对关键宏（0xB6 / 0x04 / 0x12）无误
- 温度 27°C 反推正好是寄存器复位默认值，不能作为加速度计活着的证据

**结论（暂定）：** 寄存器文件可读写，但加速度测量引擎从不启动；软件侧能排除的已全部排除，疑似板载 IMU 局部损伤。下一步：借好板交叉验证

## 2026-10-11 电机调试


### 问题 1：电机恒 MOTOR_OFFLINE，回调不触发，电机不转

**操作：**

- live watch 看 ESR = 0xFFF80057：REC=255、TEC=248、BOFF=1
- 线序/电源/极性/GND 逐项查过均正常，同设备其他同学可跑
- diff 官方例程 can.ioc：官方 CAN1_TX = PD1，本工程配成 PH13，can.c 的 MSP 初始化代码实锤

**发现错误：**

- CubeMX 引脚点错，CAN_TX 输出到悬空的 PH13，电调收不到帧也无法 ACK → TEC 爆表 → bus-off

**修改后：** ESR=0，ecd 实时更新，AliveFlag 增长，MotorState→ONLINE

### 问题 2：初始化函数无人调用（烧录前静态自查发现）

**操作：**

- 全仓库搜 `bsp_Init()` / `PWM_Init()` 调用点：零调用

**发现错误：**

- CAN 永不启动、串口死寂、加热 PWM 不跑

**修复：** `Threads_Init()` 顶部调用两个初始化


### 问题 3：ecd 差分回绕模数错误

**现象：** 手拧轴 positionFdb 先增后减，一圈仅 0.03~0.07 rad 且不稳

**发现错误：**

- ecd 是 13 位编码器（0~8191），差分强转 int16 隐含"65536 回绕"假设 → 每次跨 8192 边界注入 −8192 误差；输出轴一圈跨 36 次，误差与真实位移恰好抵消

**修复：** `if (diff > 4096) diff -= 8192; if (diff < -4096) diff += 8192;`

**验证：** 单调累积，一圈 ≈ 0.1745 rad（2π/36）

### 问题 4：ctrl 线程"单向门"

**现象：** STAGE=1 但 controlMode 恒 RELAX；而 speedSet=5（SPD 被设过的铁证）、MotorState=ONLINE

**发现错误：**

- 入口设 SPD 是一次性写入；启动最初 100ms 内 MotorState 仍是初始 OFFLINE，离线保护盖成 RELAX 后没有任何代码把 SPD 写回来

**修复：** 每循环重判——ONLINE → target_mode，OFFLINE → RELAX

**验证：** controlMode 稳定 SPD，不再回退

### 问题 5：PID 清零桩残留

**现象：** SPD 模式下电机仍不转

**发现错误：**

- pid.cpp UpdateResult() 末尾残留骨架桩 `result = 0`，算完即清零

**修复：** 删除桩代码三行

**验证：** speedPid.result、currentSet 非零

### 问题 6：速度环增益量级错 10³ + 积分风车

**现象：** 旧参数（Kp=2.0 / Ki=0.1）POS 模式周期性正反转、幅值递增，速度极快

**发现错误：**

- 电流命令单位 1000 = 1 A → Kp=2 仅 2 mA/(rad/s)，实际出力全靠 Ki 充至 2500（2.5 A）；转向反转后积分放电滞后，每振荡周期净注入能量 → 发散

**修复：** speedPid = 500~1000 / 5 / maxIOut 800；positionPid = 4 / 0 / 0 / maxOut 30；maxCurrent 首测压至 3000

**验证：** SPD 收敛至 5 rad/s；POS 到位停住无振荡
